Assistance

Créer une copie déverrouillée

  1. Sélectionnez un ou plusieurs fichiers PDF.
  2. Saisissez le mot de passe utilisé pour ouvrir les documents.
  3. Cliquez sur Déverrouiller.

PDF Unlock crée les copies dans un sous-dossier unlocked. Les fichiers originaux restent inchangés.

Résultats

La table indique séparément les réussites, les mots de passe incorrects, les PDF déjà déverrouillés et les erreurs de lecture ou d’écriture.
